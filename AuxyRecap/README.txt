Auxy Recap - level recap for WoW Forever
(Deutsch: siehe unten / see below)

Install
  Copy the folder "AuxyRecap" (from the zip) to
  World of Warcraft\_forever_\Interface\AddOns\
  then restart WoW.

What it does
  After every level-up a small window shows how the level went: time,
  XP per hour, kills, quests, deaths, gold earned/spent, compared with your
  last level, plus a forecast for the next one. Below that: lots of small
  fun stats (distance, jumps, favourite enemy, mounted time, best find,
  where your gold went ...). Everything is saved per character.

Commands (/auxyrecap or /recap)
  (empty)   last recap          now      current level so far
  history   all levels          total    sum over all levels
  test      example values      menu     settings
  reset     reset position      debug    counters for troubleshooting
  Right-click the title bar for settings. Drag the title bar to move.

Notes
  The first level is incomplete if you install the addon mid-level
  (kills/quests before that are unknown; time is read from /played).
  Kills are counted from the "dies, you gain X experience" messages,
  so grey mobs without XP are not counted.

Auxy Recap - Level-Rueckblick fuer WoW Forever

Installation
  Ordner "AuxyRecap" nach World of Warcraft\_forever_\Interface\AddOns\
  kopieren und WoW neu starten.

Was es macht
  Nach jedem Level-Up zeigt ein kleines Fenster den Rueckblick: Dauer,
  XP pro Stunde, Kills, Quests, Tode, Gold rein und raus, im Vergleich zum
  letzten Level, dazu eine Prognose fuers naechste. Darunter viele kleine
  Funstats (Strecke, Spruenge, Lieblingsgegner, Zeit auf dem Reittier,
  bester Fund, wohin das Gold ging ...). Alles pro Charakter gespeichert.

Befehle (/auxyrecap oder /recap)
  (leer) letzter Rueckblick      jetzt    Zwischenstand
  verlauf alle Level             gesamt   Summe aller Level
  test   Beispielwerte           menue    Einstellungen
  reset  Position zuruecksetzen  debug    Zaehler zur Fehlersuche
  Rechtsklick auf die Titelzeile = Einstellungen, Titelzeile ziehen = verschieben.

Hinweise
  Das erste Level ist unvollstaendig, wenn das Addon mitten im Level dazukommt
  (Kills/Quests davor unbekannt; die Zeit wird aus /played gelesen).
  Kills werden aus den Meldungen "... stirbt, Ihr bekommt X Erfahrung" gezaehlt,
  graue Gegner ohne XP zaehlen also nicht.
